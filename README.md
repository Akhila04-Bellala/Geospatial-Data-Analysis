# Geospatial Data Analysis – Regional Market Opportunities in India

## Project Overview
This project analyzes regional market opportunities across Indian cities using Python and geospatial visualization techniques.

## Objectives
- Analyze regional market demand.
- Evaluate competition and customer conversion.
- Identify underserved market opportunities.
- Visualize geographical patterns using an interactive map.

## Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Folium

## Project Workflow
1. Dataset inspection and cleaning.
2. Regional market aggregation.
3. Market opportunity scoring.
4. Interactive geographical mapping.
5. Identification of the top three potential regions.
6. Report generation.

## Project Deliverables
- Python Jupyter Notebook
- Interactive India Geospatial Map (HTML)
- Regional Market Analysis (CSV)
- Top 3 Underserved Regions (CSV)
- Geospatial Analysis Report (PDF)

## Methodology
A weighted market opportunity score was calculated using search demand, competition, conversion rate, income and acquisition cost.

## Conclusion
The analysis identifies promising regional markets for further business expansion research based on the available market indicators.
